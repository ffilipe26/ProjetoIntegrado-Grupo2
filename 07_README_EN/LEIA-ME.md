# 07 – README técnico em inglês (11 e 12/11)

Nome do arquivo final: `Grupo02_README.md`

O README deve permitir que alguém com conhecimento básico de tecnologia entenda o projeto e reproduza a demonstração. Seções pedidas:

- Project title and overview
- Problem addressed and main features
- Requirements and tools
- Setup and run instructions, in numbered steps
- How to test or reproduce the demonstration
- Brief architecture description and known limitations

Base em português: `codigo/COMO_RODAR.md` (passos) e `codigo/IMPLEMENTACAO.md` (funcionalidades e limitações).

As instruções precisam bater com os arquivos entregues. Não colocar senhas nem dados de acesso.
