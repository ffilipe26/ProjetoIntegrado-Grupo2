## O que é o projeto

Um "mini Google Drive": um computador roda o servidor (programa em Python) e outros dispositivos acessam pelo navegador para **enviar, listar e baixar arquivos**. O trabalho mostra a rede (Redes), os componentes conversando e o que acontece quando o servidor falha (Sistemas Distribuídos), e tem documentação e apresentação em inglês (Inglês).

## Como rodar o protótipo (resumo)

1. Ter o Python 3 instalado (`python --version` no terminal).
2. Abrir o terminal dentro da pasta `codigo`.
3. Rodar `python servidor.py`.
4. Abrir `http://localhost:8000` no navegador.

Passo a passo completo em `codigo/COMO_RODAR.md`.
